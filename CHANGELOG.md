# Changelog

All notable changes to Nebula Violet Theme. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the build turns each release into the
plugin's Marketplace change notes.

## [Unreleased]

### Fixed

- **Nebula Violet**: the default button is a slightly deeper violet, so its white text meets WCAG AA
  contrast. It now matches the Midnight and Colorblind themes.

## [1.1.0] - 2026-11-13

### Added

- New **Light** and **Midnight** themes alongside the original dark Nebula Violet.
- New **Colorblind** palette for all three brightness levels. Its syntax, diff, file-status and
  console colors stay distinguishable with protanopia, deuteranopia and tritanopia.
- Every theme comes in a classic and an Islands version (12 themes in total), each with a matching
  editor color scheme.
- The new themes meet WCAG AA contrast for text, including default buttons and inlay hints.

## [1.0.0] - 2026-11-10

### Added

- Initial release with two variants: **Nebula Violet** (classic) and **Nebula Violet Islands**
  (Islands UI, 2025.3+).
- Matching *Nebula Violet* editor color scheme.
